# NSB Tools — product backlog (0-1 / 1-100)

This folder is the **operating layer**: north star, metrics, honest gaps, and **actionable tickets** you (and specialized agents) work through. It is not marketing copy for the site.

**Full playbook (tickets + agents + JSON charters + ethics + weekly rhythm):** [`instructions.mf`](instructions.mf)

## How to use it (short)

1. **Weekly:** Open `metrics-scorecard.md`, update numbers, note one bet for the next week.
2. **When planning:** `active-priorities.md` holds the current slice; spin agents from `workstreams-and-agents.md`.
3. **When executing:** Add or update files under `tickets/`; move done items to an archive section or `tickets/done/` later if you want history.
4. **When spinning Cursor:** follow **`instructions.mf`** — one ticket, one charter, paste prompt + acceptance criteria.

## File map

| File | Purpose |
|------|---------|
| **`instructions.mf`** | **Playbook:** tickets + agents + charter JSON + psychology/ethics + what else to leverage |
| `north-star.md` | Goal ($3k post-tax post-fees), assumptions, milestone ladder |
| `metrics-scorecard.md` | Leading/lagging metrics, definitions, review cadence |
| `staff-pm-system-audit.md` | Cross-functional gaps (Eng / UX / Growth / Monetization / Ops) |
| `workstreams-and-agents.md` | Who does what; which agents to spin up in Cursor (or IRL roles) |
| `charterfile/` | Agent charters (`*.json`) + `prompts/*.md` + `manifest.json` for plug-and-play |
| `active-priorities.md` | Now / next / later (single source for focus) |
| `tickets/` | One file per substantial piece of work; **start at `tickets/README.md`** for the full index |

## Status labels (in tickets)

Use in the frontmatter or first line: `draft` | `ready` | `in_progress` | `blocked` | `done`
