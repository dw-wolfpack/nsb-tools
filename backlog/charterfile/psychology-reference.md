# Growth.Design psychology — NSB condensed reference

**Source:** [growth.design/psychology](https://growth.design/psychology) (106 cognitive biases & principles grouped by how people decide.)

Use this with charters **`psychology-perception-meaning`**, **`psychology-action-memory`**, and (for ship gates) **`psychology-ethics-review`**. Growth.Design summarizes the user cycle as:

1. **Filter information** → what gets noticed  
2. **Seek meaning** → story / mental model  
3. **Act in time** → shortcuts, habits, effort  
4. **Store in memory** → what sticks later  

## By phase (non-exhaustive; use site for depth)

### Information (filtering)

| Principle | One-line |
|-----------|----------|
| Hick's Law | More options → harder choice; simplify or stage. |
| Cognitive load | Cut mental effort on core task; defer advanced. |
| Progressive disclosure | Complexity after first success. |
| Anchoring | First number/frame sets expectations — set honestly. |
| Fitts's Law | Big, close targets for primary actions (esp. mobile). |
| Banner blindness | Critical guidance in real content, not only promo strips. |
| Framing | Same facts, different emphasis — stay truthful. |
| Nudge | Small hints — ethical only, no tricks. |

### Meaning (sense-making)

| Principle | One-line |
|-----------|----------|
| Mental model | Match what users already believe about “how this works.” |
| Social proof | Others’ behavior/evidence — **only if real.** |
| Curiosity gap | Tease real missing info — no bait-and-switch. |
| Familiarity bias | Prefer recognizable patterns/labels. |
| Aha! moment | First clear win fast. |
| Goal gradient | Motivation rises near completion — show real progress. |
| Occam’s Razor | Prefer the simpler explanation and UI. |

### Time (action under pressure)

| Principle | One-line |
|-----------|----------|
| Default bias | Defaults stick — choose them deliberately. |
| Loss aversion | Losses loom larger — **don’t lie** about what’s at stake. |
| Reactance | Forcing creates pushback — preserve autonomy in paywalls. |
| Decision fatigue | Too many decisions → worse choices; batch or defer. |
| Feedback loop | Immediate, clear reaction after each action. |
| Hyperbolic discounting | Now beats later — make “do it now” actually small. |

### Memory (what remains)

| Principle | One-line |
|-----------|----------|
| Peak-end rule | Judged by peak + ending — nail success and goodbye. |
| Chunking | Group information for recall (sections, bullets). |
| Recognition over recall | Show choices/labels instead of blank recall. |
| Endowment effect | “Their” saves/presets feel valuable — respect that. |
| Provide exit points | Let people leave cleanly (also builds trust). |

## Ethics (NSB default)

- No fake scarcity, timers, testimonials, or user counts.  
- No dark patterns on checkout or cancel.  
- Privacy posture stays honest (see analytics/privacy tickets).  

**Red-team pass:** before merging money-path or analytics changes, run the **`psychology-ethics-review`** charter (Block / Fix / Watch). It catches drift that “optimization” sessions can introduce.
