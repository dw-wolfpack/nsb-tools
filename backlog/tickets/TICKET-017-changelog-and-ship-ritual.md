# TICKET-017: Changelog + ship ritual

**Status:** ready  
**Band:** P2  
**Workstream:** Product  
**Agent hint:** PM agent

## Problem

Shipping without **visible narrative** loses trust and email fodder. `/changelog/` exists—keep it honest and regular.

## Outcome

Rule: **user-facing** changes hit changelog in the same deploy week. Tie to email cadence (TICKET-008) when possible.

## Acceptance criteria

- [ ] Changelog entry format agreed (date, bullets, links).
- [ ] Backfill last **N** meaningful ships if empty-looking.
- [ ] Link from footer or updates if not already obvious.

## Metrics

- Leading: cadence (entries per month).
- Lagging: repeat visitors (weak proxy via analytics).
